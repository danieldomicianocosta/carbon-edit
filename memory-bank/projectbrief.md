# Project Brief: Carbon Backend

## Overview
Carbon Backend is a Java Spring Boot application that appears to manage proposals in a business context. The system handles various aspects of proposals including their creation, status management, document handling, and analysis.

## Core Requirements
1. Manage the complete lifecycle of proposals
2. Track proposal status changes according to business rules
3. Store and retrieve proposal details, documents, and related information
4. Provide analysis capabilities for proposals
5. Implement proper security and access control

## Goals
1. Create a robust backend system for proposal management
2. Implement business rules for proposal status transitions
3. Provide comprehensive API endpoints for frontend integration
4. Ensure data integrity and security
5. Support analysis and reporting on proposal data

## Scope
The system encompasses:
- Proposal creation and management
- Proposal status workflow
- Document handling
- Commission tracking
- Vehicle details management
- Analysis and reporting
- Security and access control

## Key Stakeholders
- Sales teams (using the proposal system)
- Backoffice teams (validating proposals)
- Management (analyzing proposal data)
- Customers (subjects of the proposals)

## Success Criteria
1. Reliable proposal management system
2. Correct implementation of business rules
3. Secure and performant API
4. Comprehensive data model supporting all business requirements
5. Extensible architecture for future enhancements
